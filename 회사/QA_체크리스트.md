# QA 체크리스트 — Studio 스크린샷 검수

커밋 전 총괄(또는 QA)이 쓴다. 근거는 `스타일바이블.md` 번호. 판정: **통과 / 반려**. NG 가 하나라도 있으면 반려.

## 0. 준비
- [ ] 자동 검사 전부 통과(핸드북_QA.md 의 명령들) · 출력 창에 빨간 오류 없음 · F2 디버그 콘솔이 뜸
- [ ] Studio 동기화 후 확인할 속성 세팅. 보스 시험이면 `workspace.CombatShowcase = false`
- [ ] 변형 A/B/C 가 있으면 속성 값을 바꿔 가며 같은 순간 촬영
- [ ] 촬영 목록(기술·순간·시점)을 미리 적어 둔다 — 한 번에 찍고 사용자 화면을 오래 붙잡지 않는다

## 1. 찍는 순간 (기술마다 세 장 이상)
| 순간 | 언제 | 무엇을 본다 |
|---|---|---|
| 예고 | 칸 표시·예고 꼬리표가 뜬 직후 | 칸이 보이는가 · 캐릭터가 칸에 덮이지 않는가 · 범위가 설명과 같은가 |
| 타격 | 피해가 들어가는 프레임(흰 섬광 최대) | 캐릭터가 보이는가 · 섬광이 판을 덮지 않는가 · 셰이크 · 입자 과다 |
| 여운 | 타격 후 0.5~1초 | 연기 없음 · 잔광이 캐릭터를 가리지 않는가 · 칸이 다시 보이는가 |
연속 동작(카메라 이동)은 0.2~0.3초 간격 연속 촬영으로 "멈춤"을 본다.

## 2. 항목

### 이펙트 (바이블 1)
- [ ] 1.1 **연기 없음** — 회색/흰 뭉게 구름 질감이 어디에도 없다(안개 낀 듯한 층 포함)
- [ ] 1.2 **흰 섬광이 0.1~0.2초** — 연속 촬영에서 흰 화면이 2~3프레임(30fps 기준 6프레임 이내)만 보인다
- [ ] 1.3 **캐릭터 가시성** — 타격 순간에도 아군·적 실루엣과 얼굴/무기가 구분된다
- [ ] 1.4 **은하 중앙** 과한 반짝 없음, 밝은 점 하나가 화면을 지배하지 않는다
- [ ] 1.5 사각별 반짝이 유지되어 있다(삭제·감소 안 됨)
- [ ] 1.6 **큰 글자 컷인 없음**(FINISHER·PIN! 류 화면 글자)
- [ ] 1.7 팩 플립북/묶음이 쓰였다(단색 블록 도형만으로 끝나지 않음) · 블록 이펙트 위에 겹침
- [ ] 1.8 서포트 이펙트가 **받는 아군에게만**, 칸마다 같은 이펙트가 복제되지 않음
- [ ] 1.9 판 전체 기술은 판 끝(네 변)까지 진짜 전체로 보인다
- [ ] 1.13 입자 과다 없음 — 화면이 하얗게/뿌옇게 되지 않고, 프레임 드랍이 없다

### 카메라 (바이블 2)
- [ ] 2.1 높은 곳에서 약간 내려다본다(별을 크게 올려다보지 않음)
- [ ] 2.2 북두칠성이면 리듬이 가속("띵 - 띵-띵ㅡ 띠디디디딩- 쿠구구구구... 콰앙!!!")
- [ ] 2.3 **별마다 카메라가 멈추지 않는다**(연속 촬영에서 같은 구도가 0.3초 넘게 반복되지 않음)
- [ ] 2.4 강타 순간에만 강한 셰이크, 평소엔 과하지 않다(화면 멀미 수준 아님)
- [ ] 2.5 칼리스토전 카메라 = 아군 뒤 높은 와이드 + 천천히 떠다님
- [ ] 별자리와 레이저 착점이 한 화면에 들어온다

### 모션 (바이블 3)
- [ ] 3.1 강중약 박자 — 느린 프레임/정지가 센 박 뒤에 있다(고른 속도 아님)
- [ ] 3.2 칼날이 면이 아니라 날로 벤다
- [ ] 3.3 망치 대기 자세 = 아래팔 세워 어깨에 걸침
- [ ] 3.4 다단히트가 타마다 따로 맞는 것처럼 보이고 숫자도 타마다 뜬다
- [ ] 무기가 땅·몸을 파고들지 않는다

### UI (바이블 4, 5)
- [ ] 4.1 칸이 스킬 중에도 **보인다**(숨겨지지 않음)
- [ ] 4.2 칸 면이 캐릭터를 덮지 않고, 하이라이트는 윤곽만
- [ ] 4.3 **자동 번역 없음** — 툴팁·버튼·보스 말풍선이 한국어 원문 그대로(영어/기계 번역 섞이지 않음). 새 텍스트의 `AutoLocalize = false`
- [ ] 4.4 문구가 지침대로("~한다", 용어 통일) · 줄바꿈·키워드 색이 정상
- [ ] 글자가 잘리거나 겹치지 않는다(모바일 비율 포함)

### 외형/아트 (바이블 7)
- [ ] 7.1 칼리스토 1·2페이즈 옷이 건드려지지 않았다
- [ ] 7.2 의수·별 눈가림 유지, 표정 변화 없음(무표정)
- [ ] 아이콘 48px·32px 윤곽 구분, 그림에 글자 없음

### 밸런스/규칙 (바이블 6, 8)
- [ ] 십자 표시는 파라티리시·심베라즈마·메그레즈 **셋에만**, 나머지 유도기는 원래 모양
- [ ] 판 전체 기술은 잠기리·알리오스·북두칠성·케노스
- [ ] 지시 밖 수치가 바뀌지 않았다(diff 에서 수치 변경 라인 확인)
- [ ] 결투사의 받는 피해 0 을 버그로 "고치지" 않았다

## 3. 통과/반려 기준
- **통과**: 체크한 모든 항목 OK, 자동 검사 전부 통과, 변형이 있으면 기본값이 정해짐.
- **반려(즉시)**: 연기 · 큰 컷인 · 캐릭터가 안 보임 · 카메라가 별마다 멈춤 · 클라 오류/콘솔 사라짐 · 자동 번역 · 지시 밖 밸런스 수정.
- **조건부 통과**: 사소한 크기·색 취향 → 변형 A/B/C 로 사용자가 고르게 두고 통과(기본값 명시).
- 반려 시 보고: 항목 번호 + 스크린샷 번호 + 되돌릴 부서 + 한 줄 수정 방향.
- 사용자에게는 **통과본만** 보여 주고, 확인 요청은 3개 이내로 줄인다.
