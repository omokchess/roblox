# 핸드북 — 밸런싱 부서

먼저 읽기: `회사/스타일바이블.md` 6(밸런스)·8(칼리스토)·10절. 공통 금지는 `README.md`. **일이 있을 때만 부른다.**

## 역할
피해 공식 수치, 쿨타임, 카드·스킬·보스 수치를 시뮬로 재고 조정안을 낸다. 지시된 범위 **밖**의 문제는 고치지 않고 보고한다.

## 확정된 것 (사용자 지정 — 뒤집지 말 것)
- 공식: `base = skill×(1+weapon)` → `flat = base×(1+buffs)` → `dmg = flat×(1+skills)×(1+def)` → `crit = dmg×(2+crit_dmg)`. **`BattleStatus.Damage` 한 곳**에서만 계산. 칸 안도 곱연산, `def` 만 합(받는 피해량·속성 저항·기름+불·과부하).
- 무기 공격력 1 = +1%. 화상 = 최대 체력×(2%+0.1%×수치). 융해 = (화상×융해)÷2, 상한 100×융해. 파상풍은 가하는 피해량 칸의 한 항(0.85^수치−1).
- 체력 비례 피해 대폭 너프: 출혈 2%·블루스크린 20%·연쇄 15%·검수 4%·파상풍 발작 4%·경련 1%. 칼리스토 도트 상한 턴당 3%, 전용 출혈 비율 없음.
- 다단히트는 타마다 독립 타격, 보정 0 일 때 새 총합 = 옛 총합(한 방×1.2).
- **결투사의 받는 피해 0 은 의도**. 버그로 보고하지 않는다.
- 치명 기본 200%(적도 동일).

## 규칙
- 수치를 바꾸기 전 **현재 값을 시뮬로 먼저 재서 기록**(전), 바꾼 뒤 다시 잰다(후).
- 지시 밖 밸런스 문제 → **보고만**(알리오스가 광역에서 단일타격이 되며 약해진 것처럼 부작용은 질문 md 에 적고 "밸런스는 따로 봐 주세요").
- 사용자가 정한 방식(추적, 실시간 유도, QTE "입력을 훨씬 어렵게")은 줄이거나 뒤집지 않는다.
- 쿨타임을 늘리면 평타 연타가 늘 수 있다 — 반복 방지 규칙(R2: 평타 2연속 뒤엔 재사용 1 이하 남은 기술을 쓴다)을 확인.
- 한 직업만 약해졌다고 판단하기 전에 `damage_sim` 으로 9직업을 모두 비교.
- 밸런스 근거 없는 숫자("대충 3턴")는 쓰지 않는다. 시뮬 출력 또는 사용자 말을 인용.

## 과거 사고와 교훈
- 공식을 칸 안 합연산으로 처음 구현 → 사용자 답으로 곱연산으로 정정(c685b9a). **공식 해석은 질문 md 에 올려 확인**.
- 칼리스토 도트가 상한을 우회(화상 발동·융해 폭발이 상한 40 미적용) → 1e9bc73 수정. 새 도트를 넣을 땐 상한 우회 경로를 grep.
- 체력 비례 피해가 칼리스토를 단독 클리어 가능하게 함 → 도트 상한 3%.
- 궁극기를 사용자가 본 적이 없다고 해서 보장 규칙을 넣음 — 확률 기대값이 아니라 **최악의 턴 수** 로 검사.
- 지시 밖 수정 금지 규칙이 생긴 계기: 밸런스 변경이 의도치 않게 다른 직업까지 흔듦.
