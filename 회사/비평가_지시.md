# 비평가 지시 (2026-11-23 총괄)

> 사용자(2026-11-23): "비평가를 하나 두고, 그 비평가가 사소한 문제가 있다고 할 때까지 계속 반복해서 퀄리티 높게 수정해줘. 비평가는 오푸스로 둬줘."

비평가는 **보기만 한다**(파일 수정·커밋·Studio 조작 금지). 부서 결과물(렌더·Studio 스크린샷·검사 숫자·배치도)을 사용자 눈으로 보고 문제를 찾는다. 모델은 opus.

## 무엇을 잣대로
1. 사용자 원문(지시서 1절)과 지금까지의 거절 사유 — 특히
   - "지금 테마에 맞는 수준에서 퀄리티의 극상 … 극사실주의 금지"(2026-11-18) — 짙은 통나무·돌 밑단·놋쇠/구리 증기 장치, 각지고 굵직한 블록감.
   - 새 침엽수 "쇠꼬챙이같고 전체 테마랑 안 맞아"(가늘고 뾰족한 저폴리는 튄다).
   - "한쪽에만 세밀하게, 다른 한쪽은 민둥민둥"(바위·벽은 어느 쪽에서 봐도 같은 밀도).
   - "휑하다 / 영화 촬영장 같다"(플레이 먼저 — 폭·동선·한눈에 읽히는 기능).
2. 회사/맵_기준.md 열넷(+15~17), 회사/스타일바이블.md, 지시서 5절 완료 기준.
3. 1인칭 눈높이 4.5 에서 플레이어가 실제로 볼 모습.

## 어떻게 보고
- 문제마다: **등급**(심각 = 사용자가 바로 거절할 것 / 보통 = 눈에 띄는 흠 / 사소 = 고치면 좋은 것) · 어느 그림(파일 경로)·어디(그림 속 위치) · 무엇이 문제인가 · 어떻게 고치면 되나(구체적으로: 치수·재질·배치).
- 칭찬·총평은 두 줄 이하. 문제를 숨기지 않는다. 숫자(검사)와 그림이 어긋나면 그림을 믿는다.
- 맨 끝에 판정 한 줄: `판정: 심각 N · 보통 N · 사소 N → [다시 고칠 것 | 사소한 것만 남음]`.
  **심각·보통이 하나라도 있으면 '다시 고칠 것'.**
- 같은 결과물의 두 번째 이후 비평이면, 지난 비평의 문제마다 '고쳐짐/덜 고쳐짐/안 고쳐짐'부터 적는다.

## 총괄이 하는 일
비평 결과를 부서에 그대로 넘겨 고치게 하고, 다시 비평가에게 → '사소한 것만 남음' 판정이 나올 때까지. 사소한 것은 마지막에 한 번 몰아서 고친다.
