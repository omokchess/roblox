# 핸드북 — 아트 부서

먼저 읽기: `회사/스타일바이블.md` 4.6·7절, `art/스타일가이드.md`(원본). 공통 금지는 `README.md`.

## 역할
게임에 들어가는 그림 전부: 카드 그림, 상태이상 아이콘, 컷인 시안, UI 아이콘, 블렌더 모델 외형(무기·복장). 코드(`src/**`)는 건드리지 않는다 — 연결은 프로그래밍 부서/총괄.

## 쓰는 파일
| 파일 | 용도 |
|---|---|
| `art/스타일가이드.md` | 공통 톤·규격·이름 규칙·업로드 절차 |
| `tools/art/artlib.py` | 공용 도구(거리장 렌더, 윤곽, 그라디언트) |
| `tools/art/status_icons.py` | 상태이상 아이콘 37종(256px, `art/status/<KeywordId>.png`) |
| `tools/art/card_samples.py` | 카드 그림 견본·비교판(`art/cards/`) |
| `tools/art/finisher_cutin.py` | (폐기된) FINISHER/PIN 컷인 시안 — 컷인은 사용자가 금지함, 새로 만들지 않는다 |
| `tools/art/ui_icons.py` | UI 아이콘(로프·기믹 칩 4종 등) |
| `tools/card_art/build.py` + `specs/*.py` | 현재 게임의 카드 그림 생성기(도형 Frame 방식, `src/shared/CardArtworksGen/<직업>.luau` 에 적음) |
| `src/shared/Keywords.luau` | 상태이상 Id·종류·**색**(읽기) |
| `models/*.py`, `models/*.glb` | 블렌더 모델 |
| `tools/art/*` 가 읽는 직업 색 | `CardAxes`(스타일가이드 표) |

## 명령
```
BPY="C:/Program Files/Blender Foundation/Blender 5.2/5.2/python/bin/python.exe"   # numpy·PIL 있음. 시스템 파이썬 3.10 엔 없음
cd "/c/PROJECT-EDIT(by roblox)"
"$BPY" tools/art/status_icons.py [Id ...]    # 전체 약 2분, Id 를 주면 그것만 → art/status/*.png, _sheet.png
"$BPY" tools/art/card_samples.py             # 견본 3장 + 비교판 약 1분
"C:/Program Files/Blender Foundation/Blender 5.2/blender.exe" -b -P <블렌더 스크립트>   # 모델 작업
```
**결과 파일을 직접 고치지 말고 스크립트를 고쳐 다시 돌린다.** 검수는 `_sheet.png`(128px / 48px / 32px / 밝은 바탕 32px)를 열어서 눈으로 + 확대 크롭으로.

## 양식 요약
- 톤: 어두운 우주·천문. 바탕 `#070912`, 빛은 그 그림의 색 하나. 두꺼운 어두운 윤곽(`#080a12`) + 위 밝고 아래 어두운 면 + 작은 흰 하이라이트. **그림 안에 글자·숫자 금지.**
- 상태이상 틀: 이로움=원, 해로움=둥근 육각, 그 밖=둥근 네모. 색은 `Keywords.luau` 의 `Color`(너무 어두우면 자동으로 밝힘). **48px·32px 에서 윤곽만으로 구분**돼야 통과.
- 카드: 512×512, 주인공 가운데 70%, 상징 하나를 55~70% 크게, 직업색 번지는 빛 + 별가루, 등급 테두리(일반 `#aaacba`·희귀 `#78afff`·필수 `#d6a0ff`).
- 업로드 규격: PNG 정사각, 최대 1024×1024, 20MB 이하, sRGB, 알파. 업로드와 asset id 연결(`ArtAssets.luau`)은 **총괄**이 한다.

## 이펙트에 관한 연결 규칙
- 아트가 만든 밝은 후광·광채가 캐릭터를 가리지 않게(스타일바이블 1.3). 시안에 연기 질감 금지.
- 별은 실제 별 색(분광형)·겉보기 등급 크기를 따를 때가 있다(북두칠성).
- 칼리스토 옷: 1·2페이즈는 카탈로그 셔츠·바지 사용, **동업자가 전면 수정 예정이라 건드리지 않는다.** 의수는 말레니아 참고, 별 눈가리개.

## 과거 사고와 교훈
- 카드 그림은 이미지가 아니라 GUI 도형이다(CardArt/CardView.PaintArt) — 이미지 PNG 를 만들어도 연결 코드가 없으면 게임에 안 나온다. 지시서에 "견본까지" 인지 "연결까지" 인지 명시.
- 상태이상 아이콘은 `BattleHud.statusChips` 글자 칩이 폴백 — 아이콘이 없어도 게임이 깨지지 않는다.
- FINISHER·PIN! 컷인 시안은 만들었으나 사용자가 "이펙트를 다 가림"으로 삭제 지시 → 큰 글자 컷인 기획 자체를 만들지 않는다.
- 시스템 파이썬엔 numpy·PIL 이 없어서 한 번 막힘 → 블렌더 안 파이썬 사용.
- 블렌더 렌더러는 2D 아이콘에는 쓰지 않는다(numpy 거리장 + 3배 초과표본이 빠르고 결과가 일정).
- 같은 Id 는 같은 아이콘(대소문자 포함).

## 금지
커밋·Studio 조작·업로드(총괄), 다른 부서 파일 동시 수정, `git stash`, `src/**` 수정, 결과 이미지를 손으로 고치기, 그림 안에 글자 넣기.
