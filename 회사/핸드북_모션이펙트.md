## VFX 팩 쓰는 법
- 블록 이펙트(모양·판정이 읽히는 것) **위에** 팩을 겹친다.
- `CombatVfx.Pack("팩/이펙트", cf, { Size, Scale, Color, Tint, Count, Time, Attach })` — `ReplicatedStorage.VfxLibrary`(Studio 에만 존재). 없는 이름이면 `false` → 블록 이펙트로 대신. 연기 이미터는 자동으로 걷힌다.
- `CombatVfx.Flipbook(at, { Texture, Layout = "Grid2x2"|"Grid4x4"|"Grid8x8", Mode, Framerate, Size, Color, Transparency, LightEmission, Count, Life, Speed, Spread, Rotation, Accel, Orientation, ZOffset, Rate, Duration, Attach })` — 텍스처·`flip=` 값은 `vfx_textures.tsv` 에서 찾는다. 방향은 cf 의 위쪽.
- 팩 목록: `vfx pack`(Explosion·Projectile) · `Big` · `Anime`(Slash·Impact·Blood·Fire·Wind·Lighting·Stars·Crack·Shield…) · `Heads` · `Beams` · `Auras` · `Loose`(Flash·Shockwave·Sparkles) · `Textures`. 팩 새로 들여올 땐 `tools/Vfx_Import.luau`(총괄이 Studio 에서 실행).
- 밝은 층을 쌓을 땐 팩 `LightEmission` 과 흰 섬광 길이(0.1~0.2초)를 확인.

## 모션 규칙 요약
각도: 옆에서 본 무기 각 = 팔X + 90 + 무기 숙임 − 몸통 숙임(180 위, 210 어깨에 멤, 315 뒤로 끎). 강중약 박자 주석. 칼날은 날로. 긴 무기는 땅·몸 파고듦 점검. 다단히트는 독립 타격.

## 과거 사고와 교훈 (커밋 로그)
- `LineJoin` → 없는 속성: `UIStroke.LineJoinMode` 가 맞다. 클라 시작이 멈춰 디버그 콘솔(F2)이 사라졌다(e3e57ee). **새 속성·Enum 은 `tools/roblox_api/API-Dump.json` 또는 공식 문서로 확인**한 뒤 쓴다.
- `NumberRange` 오류 둘: 최솟값 > 최댓값이면 오류(6bdd9a0 Sparks 속도, 22257b4 Flipbook Rotation·Speed 음수). → 항상 `min ≤ max`, 음수일 땐 `math.min/max` 로 정렬.
- 판 레이어 `AlwaysOnTop` 이 캐릭터를 덮음(7f65551 → c848700 되돌림). 칸 표시는 보통 깊이, 하이라이트는 윤곽만.
- **북두칠성 카메라 다섯 번 반복**(4d57fe8, 8505f3a, 49b7b91, 9528f93, 4dfcde6): 별마다 멈추는 카메라·너무 낮은 시점 지적이 반복됨. 스타일바이블 2.1~2.4 를 매번 다시 읽고, 가속 간격(0.45·0.30·0.20·0.08·0.06·0.05)과 카메라 이동이 **멈춤 없이 이어지는지** 코드로 확인.
- 컷인이 이펙트를 가림(acdb3ad, 7cb71bd): 큰 글자 컷인 만들지 않는다.
- 모션 키 사이 한 값이 180° 넘게 바뀌면 의도 없이 오일러로 돈다 → `check_wrap.py`.
- Studio 를 다시 켤 때 `CombatShowcase` 모듈이 사라지는 일(eede6e1): 모듈 없으면 건너뛰도록 처리됨. 전시장 속성은 총괄이 켜고 끈다.
- 연기 이펙트를 만들어 넣었다가 전부 제거(c848700) → 새 이펙트에 연기 텍스처가 섞이지 않았는지 `vfx_textures.tsv` 에서 이름으로 확인.
- 세션 리셋으로 부서원 대화가 사라진다 → 변경 의도는 코드 주석과 보고서에 남긴다.
