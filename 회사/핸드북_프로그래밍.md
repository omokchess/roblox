## 코드 규칙
- **줄바꿈 원래대로**: 파일마다 CRLF/LF 가 다르다(과거에 `\n` 만 써서 새로 끼운 줄만 LF 로 남은 사고, log.md 3047행). 수정 전 `file <경로>` 로 확인, Edit 도구로 필요한 줄만 바꾼다. 전체를 다시 써서 줄바꿈이 바뀌면 diff 가 전체로 번진다.
- **다른 부서 파일 동시 수정 금지.** 지시서의 "범위 파일" 밖은 읽기만. `git stash` 금지(동시 작업이 망가진다). 같은 파일에 부서 둘이 들어가면 Edit 로 필요한 줄만.
- **Bash heredoc 함정**: `python - <<'EOF'` 안 `\t`·`\n` 이 진짜 탭·줄바꿈으로 바뀐다. 백슬래시가 든 패치/정규식은 Write 로 `.py` 파일에 써서 `python 파일 인자` 로 돌린다. Lua 문자열 속 `\n` 은 Edit 로.
- **새 로블록스 속성·Enum 은 확인**: `tools/roblox_api/API-Dump.json`(없는 속성이면 런타임 오류) 또는 공식 문서. `UIStroke.LineJoinMode` 같은 이름 주의.
- **NumberRange(min, max)**: min ≤ max. 음수·역순 값이 들어올 수 있는 곳은 `math.min/max` 로 정렬.
- 새 TextLabel/TextButton/TextBox 에는 `AutoLocalize = false`.
- 클라이언트 시작 중 한 모듈이 멈추면 뒤의 UI(F2 콘솔)가 사라진다 → 시작 경로의 `require` 는 보호하고, 새 UI 코드는 `smoke_director` 로 한 번 돌린다.
- 피해는 `BattleStatus.Damage` 한 곳에서만 계산. 도트 상한(칼리스토 3%) 우회 경로를 만들지 않는다.
- 서버 판정이 정답이다. 클라 연출은 서버 스냅샷(Events)을 따라 그린다.
- 플레이 서버에는 `loadstring` 이 없다. 로더는 편집 모드에서만 동작.

## 과거 사고와 교훈
- `LineJoin` 없는 속성 → `BattleClient.new` 가 멈춰 디버그 콘솔이 사라짐(e3e57ee).
- `NumberRange` 오류 둘(6bdd9a0, 22257b4).
- 판 레이어 `AlwaysOnTop` 이 캐릭터를 덮음(c848700에서 수정).
- 도트 상한 우회(화상 발동·융해 폭발)로 칼리스토가 한 번에 녹음(1e9bc73).
- Studio 재시작 때 `CombatShowcase` 모듈이 없을 때 클라 시작 중단(eede6e1) → 없으면 건너뜀.
- 십자/X 과잉 적용(3a62a86 → 4dfcde6): 코드 쪽에선 "대상 기술 ID 목록" 을 지시서에서 받은 그대로 쓴다. 지시서에 없는 ID 를 추가하지 않는다.
- 문구 일괄 수정 중 키·로직을 건드린 사고를 막기 위해 문구 작업은 문자열 값만.
- 세션 리셋으로 부서원 대화가 사라짐 → 지시서와 보고서가 전부다. 모르면 추측하지 말고 코드/문서에서 확인.
