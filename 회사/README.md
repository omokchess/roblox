# 회사 (De profundis 개발 운영 문서)

사용자는 **총괄(메인 Claude)과만 대화**한다. 총괄은 지시를 부서로 나눠 서브에이전트(Sonnet 5.5)에게 보내고, 결과를 검수해 커밋한다. 이 폴더의 문서는 **세션이 바뀌어도 품질이 유지되게** 하는 기억이다.

## 구조
| 부서 | 하는 일 | 핸드북 |
|---|---|---|
| 총괄 | 사용자 대화, 지시서 작성(`지시서_양식.md`), 검수, **커밋·푸시·Studio 조작** | — |
| 기획 | 사양·문서·한국어 문구·질문 md, 코드 대조(읽기만) | `핸드북_기획.md` |
| 모션및이펙트 | 전투 모션·무기 자세·이펙트·카메라 | `핸드북_모션이펙트.md` |
| 밸런싱 | 피해 공식 수치·시뮬(일이 있을 때만) | `핸드북_밸런싱.md` |
| 프로그래밍 | 규칙·전투 흐름·UI 코드 | `핸드북_프로그래밍.md` |
| 아트 | 카드 그림·아이콘·블렌더 외형 | `핸드북_아트.md` |
| QA | 커밋 전 Studio 스크린샷 검수 | `핸드북_QA.md` + `QA_체크리스트.md` |

## 문서 목록과 쓰는 법
- `스타일바이블.md` — 사용자 취향·원칙·금지·칭찬받은 것(근거 원문+날짜). **모든 지시서의 첫 줄에서 읽게 한다.** 새 사용자 피드백이 오면 총괄이 해당 분야 표에 한 줄 추가(규칙 / 원문 / 날짜).
- `핸드북_*.md` — 부서별 도구·정확한 명령·과거 사고·보고 양식. 새 도구·새 사고가 생기면 해당 핸드북에 추가.
- `지시서_양식.md` — 총괄이 쓰는 지시서 틀. 첫 줄 = "바이블과 핸드북 먼저 읽어라".
- `QA_체크리스트.md` — 스크린샷 검수 항목과 통과/반려 기준.

지시서를 보낼 때: 양식을 복사 → 사용자 원문 인용 → 해석 한 줄 → 대상 목록(숫자) → 범위 파일 → 변형 여부 → 보고 항목. 배경 설명은 문서 경로로 대체.

## 승인된 운영 규칙 (사용자 승인, 2026-11-07)
1. **QA** — 커밋 전 총괄이 Studio 스크린샷으로 검수(`핸드북_QA.md`). 통과본만 사용자에게.
2. **API 검사기** — 새 로블록스 속성·Enum 은 `tools/roblox_api/API-Dump.json`/공식 문서로 확인한 뒤 쓴다(`LineJoin`·NumberRange 류 사고 방지). 검사기 스크립트화는 프로그래밍 부서 후속 과제.
3. **스타일 바이블 + 부서별 핸드북** — 취향·금지 목록을 한 문서로, 도구·검사·사고는 핸드북으로. 지시서는 "핸드북 먼저 읽어라" 한 줄.
4. **한 줄 해석 확인** — 범위가 애매한 지시는 착수 전 총괄이 해석 한 줄을 확인한다(십자/X 과잉 해석 사고).
5. **변형 동시 제작** — 주관적인 것(색·세기·리듬·거리)은 2~3안을 같이 만들어 Studio 속성 하나로 바꿔 보며 고른다.

## 모든 부서 공통 규칙
- **커밋·푸시·Studio 조작은 총괄만.** 부서는 하지 않는다.
- **다른 부서 파일을 동시에 수정하지 않는다.** 겹치면 Edit 도구로 필요한 줄만. **`git stash` 금지**(동시 작업이 망가진다).
- **CRLF/LF 줄바꿈을 원래대로** 유지(`file <경로>` 로 확인).
- **Bash heredoc 은 `\` 를 바꿔 버린다.** 백슬래시가 든 파이썬 패치·정규식은 Write 로 파일에 써서 실행.
- **새 로블록스 속성·Enum 은 확인**하고 쓴다. `NumberRange` 는 `min ≤ max`. 새 글자 UI 는 `AutoLocalize = false`.
- **지시 밖 밸런스 문제는 고치지 말고 보고.**
- **질문은 md 로**(`C:\claude\<주제>_질문.md`), 답 오기 전엔 가장 그럴듯하게 정해 진행.
- 한국어로 쓴다. 보고는 증거가 아니다 — 총괄이 diff·검사로 확인한다.
- 부서원 대화는 세션 리셋으로 사라질 수 있다 → 결정·의도는 문서와 보고서에 남긴다.
