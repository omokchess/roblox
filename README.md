# De profundis

(2026-09-29 게임 이름을 De profundis 로 바꿨다. 옛 이름 Porcelain Tactics Prototype — 저장 키·DataStore·Rojo 프로젝트 이름의 "Porcelain" 은 데이터가 끊기지 않게 그대로 둔다.)

R6 캐릭터용 모션을 직접 제작하고, 고정 스탯 캐릭터 파티로 30층 탑을 등반하는 Roblox PvE 턴제 프로토타입입니다.

## 게임 흐름

1. 중앙 광장에서 자유롭게 이동합니다.
2. 원정 게시판에서 10종 캐릭터 중 솔로 파티 3명 또는 파티 플레이 캐릭터를 고릅니다.
3. 각 층의 적과 기믹을 돌파합니다.
4. 층을 돌파할 때마다 무작위 강화 3개 중 하나를 선택합니다.
5. 10·20·30층 보스를 쓰러뜨리고 30층 정상에 도달합니다.

전투는 서버 권위이며 캐릭터당 행동은 한 번입니다. 솔로에서는 한 플레이어가 파티원 3명을 모두 조작하고, 파티에서는 최대 4명이 각자 캐릭터를 조작합니다.

## 고정 캐릭터 10종

| 캐릭터 | 역할 | 핵심 기능 |
| --- | --- | --- |
| 기사 | 균형형 | 피해와 자기 보호막 |
| 수호자 | 탱커 | 높은 체력과 대형 보호막 |
| 사수 | 원거리 딜러 | 안정적인 단일 대상 공격 |
| 광전사 | 폭딜 | 체력을 소모하는 고위력 공격 |
| 비전술사 | 유리대포 | 낮은 체력과 최고 기술 위력 |
| 성직자 | 회복 | 아군 단일 회복 |
| 연금술사 | 지속 피해 | 피해와 화상 스택 |
| 음유시인 | 버퍼 | 파티 전체 대미지 증가 |
| 암살자 | 처형 | 체력이 낮은 적 추가 피해 |
| 공예가 | 파티 방어 | 파티 전체 보호막 |

체력, 이동속도, 평타 대미지, 기술 대미지와 쿨타임은 `CharacterDefinitions.luau`에서 고정됩니다. 모션 팩을 장착해도 이 값은 바뀌지 않습니다.

## 30층 탑

- 1~30층의 적 구성과 스케일을 `TowerDefinitions.luau`에서 결정합니다.
- 5층 단위 정예전과 10·20·30층 보스전이 있습니다.
- 층 규칙은 적 보호막, 시작 화상, 적 공격력 증가, 아군 보호막, 기술 가속 등을 순환합니다.
- 매 층 돌파 후 기본 공격력, 기술 위력, 최대 체력, 쿨타임, 보호막, 회복, 정화, 일시 버프 중 3개가 제시됩니다.
- 계정 최고 도달 층은 모션 프로필과 함께 저장됩니다.

## 모션 공방과 인벤토리

- 광장의 `모션 제작`을 누르면 먼저 기준 직업을 선택한 뒤 해당 직업용 모션 세트를 제작하고 저장합니다.
- 제작 화면과 모션 인벤토리는 서로 독립된 UI이며 원정대 편성 화면을 닫아도 광장 진입 버튼이 사라지지 않습니다.
- 저장한 모션 세트는 계정의 `모션 인벤토리`에 보관되며 저장만으로 자동 장착되지 않습니다.
- `모션 인벤토리`에서 원하는 직업과 모션 세트를 차례로 선택한 뒤 `선택 모션 장착`을 누릅니다.
- 하나의 모션 세트를 여러 직업에 장착할 수 있고, 직업마다 서로 다른 모션 세트를 지정할 수도 있습니다.
- 인벤토리에는 각 모션을 만들 때 선택한 제작 기준 직업이 표시됩니다.
- 전투에서는 장착 세트 중 완성 처리된 프리셋만 해당 직업의 평타·스킬·가드 등에 사용됩니다.

- 공방 버튼을 누르면 먼저 기준 캐릭터를 선택합니다.
- 계정에 여러 모션 팩을 저장할 수 있습니다.
- 같은 모션을 여러 캐릭터에 장착하거나 캐릭터별로 다른 모션을 장착할 수 있습니다.
- 장착하지 않은 캐릭터는 내장 기본 모션을 사용합니다.
- 장착 정보와 모션 팩은 `PorcelainProfiles_v2` DataStore에 계정 단위로 저장됩니다.
- 기존 `PorcelainMotionPacks_v1` 단일 모션은 기사 장착 모션으로 자동 이전됩니다.
- 레거시 무기 `BaseStats`는 저장 검증 과정에서 폐기됩니다.

모션 팩은 포즈, 관절 이동/회전, 무기와 장식, FX, 히트박스, 타격 프레임과 대미지 분배를 정의합니다. 캐릭터의 고정 총 대미지와 쿨타임은 덮어쓰지 않으며, 모션에 작성한 대상 수·상태이상·버프 이벤트는 해당 프레임에 실행됩니다.

## 실행

1. Roblox Studio와 Rojo 플러그인을 설치합니다.
2. 이 폴더에서 `rojo serve --port 34872`를 실행합니다.
3. Studio의 Rojo 플러그인으로 `localhost:34872`에 연결합니다.
4. Play를 실행합니다.

Studio에서 계정 저장을 시험하려면 게임을 게시하고 **Game Settings > Security > Enable Studio Access to API Services**를 활성화해야 합니다. 비활성 상태에서도 현재 Studio 세션의 저장·장착은 동작하지만 재접속 영속성은 검증할 수 없습니다.

## 검증

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\check.ps1
```

검증 스크립트는 StyLua 포맷 검사, Selene 정적 분석과 `PorcelainTacticsPrototype.rbxlx` Rojo 빌드를 실행합니다. Studio 실행 시 프로토타입 테스트가 캐릭터 10종, 30층 연속 정의, 보스와 적 참조, 강화 드래프트, 모션 저장 검증을 추가로 검사합니다.

변경 내역은 [log.md](./log.md)에 누적합니다.
