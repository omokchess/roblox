# 아트 스타일 가이드 (아트팀, 2026-11-06 1차)

게임에 들어가는 그림(카드 그림·상태이상 아이콘, 이후 직업·아이템 아이콘 등)의 공통 양식. 만드는 스크립트는 `tools/art/`.

## 0. 현황 (조사 결과)

- **카드 그림은 지금 이미지가 아니다.** `tools/card_art/build.py` + `specs/*.py`(손으로 짠 도형 구성, `motifs.py` 도형 모음)가 GUI 도형(Frame+UICorner+UIStroke) 목록을 만들어 `src/shared/CardArtworksGen/<직업>.luau`(248장)에 적는다. `CardArt.luau`가 등급색 원판·테두리 링 위에 이 도형을 얹고 `CardView.PaintArt`가 Frame 으로 옮긴다. 카드의 `Art = "카드Id"` 필드가 연결 고리. 결과: 단색 바탕 + 흰 선 문양 + 강조색 하나. 업로드·asset id 는 쓰지 않는다.
- **상태이상 아이콘은 없다.** `BattleHud.luau`의 `statusChips`는 글자 칩(이름 + 수치, 색은 `Keywords.luau`의 `Color`)만 그린다. `Keywords.luau`(이름·종류 Buff/Debuff/Status/Neutral/Resource·색·설명)가 상태이상 사전이다. `상태이상.md`는 규칙 문서.
- 게임 안에 `rbxassetid`가 쓰이는 곳은 모션·이펙트 쪽(`MotionPlayer`, `Fx/Common`, `Callisto`)뿐이고 UI 그림에는 아직 없다.

## 1. 공통 톤

어두운 우주·천문 분위기. 바탕은 거의 검은 남색(`#070912`), 빛은 **그 그림의 색 하나**에서 나온다. 선 없는 사실화가 아니라 **두꺼운 어두운 윤곽(INK `#080a12`) + 위가 밝고 아래가 어두운 면 + 작은 흰 하이라이트**의 스티커형 그림. 장식 글자는 그림 안에 넣지 않는다(글자는 게임이 그린다).

## 2. 상태이상 아이콘

- 256×256 투명 PNG. 파일 `art/status/<Keywords.luau 의 Id>.png`. 같은 Id 는 같은 아이콘(대소문자 포함).
- **틀 3종**(모양으로 종류를 읽는다 — 색맹 대비): 이로운 것(Buff)=동그라미, 해로운 것(Debuff)=둥근 육각형, 그 밖(Status·Neutral·Resource)=둥근 네모.
- 틀 구성: 바깥 윤곽 → 상태색 테두리 띠(위 밝음) → 안쪽 윤곽 → 상태색을 16% 섞은 어두운 판 → 안쪽 빛. 상징은 판 중심에서 폭 약 86% 안.
- **색 = `Keywords.luau`의 `Color`**(스크립트가 읽는다. 색을 바꾸면 다시 돌리면 끝). 너무 어두운 색(파상풍 갈색)은 자동으로 밝힌다.
- 상징은 **그 상태의 뜻에서**: 출혈=핏방울, 독=해골, 화상=불꽃, 기름=기름방울+웅덩이, 파상풍=녹슨 못, 쇼크=번개, 경련=떨림 선, 그로기=소용돌이+별, 융해=녹아내리는 덩어리, 낙인=달군 쇠, 광신=빛나는 눈, 보호막=방벽 구슬, 벽=벽돌, 별 계열=북두칠성·작은곰자리(두베·알카이드·미자르는 그 별만 크게 밝힌 북두칠성)…
- 읽힘 기준: **48px와 32px에서 윤곽만으로 구분**돼야 한다. 가는 선(0.02 미만)은 장식에만 쓰고 의미를 싣지 않는다. 비교판 `_sheet.png`(위 128px, 아래 48px·32px·밝은 바탕 32px)로 확인한다.
- 비교판 순서(왼→오, 위→아래): 출혈 독 화상 기름 파상풍 쇼크 경련 그로기 / 융해 낙인 과다회복 광신 중력 감극 묶임 보호막 / 벽 자기장 브릴란테 집중력 공격태세 방어태세 도발 핵융합 / 칠성 성위-칠성 성위 뭇별 고찰 심베라즈마 칼춤상처 작은곰자리 / 두베 알카이드 미자르 성위-점멸 별빛가호.
- 1차 범위 37종. **2차 후보**: 수치 보정 12종(가하는 피해량 등 — 위·아래 화살표 문법 필요), 자원 계열(음표·박자표·집중·분노·질량·공명·허물 벽·약재·원액·병 6종·기도력). 자원은 틀 3번째 형태(둥근 네모)를 쓴다.

## 3. 카드 그림

- **512×512 정사각 PNG**(불투명, 모서리만 투명). 업로드 시 그대로. 카드 칸(`Art` 프레임)이 가로로 길어도 가운데 정사각만 쓰므로 **주인공은 가운데 70% 안**에.
- 구도: **상징 하나를 크게**(화면의 55~70%), 곁가지 2~3개는 작게. 카드 이름·효과가 한눈에 읽히는 물건/장면(지금 생성기의 `specs` 주석이 이미 그 한 줄 설명을 갖고 있다 — 그대로 재사용).
- 바탕: 어두운 남색 + **직업색**의 번지는 빛(뒤쪽) + 별가루 + 모서리 비네팅. 바깥 테두리는 **등급 색**(일반 회색 `#aaacba`, 희귀 파랑 `#78afff`, 필수 보라 `#d6a0ff` — `CardView.GRADE_STYLE.Edge`)의 이중 띠. 필수는 테두리 둘레에 광채/보석을 더한다.

## 4. 파일 이름

- 상태이상: `art/status/<KeywordId>.png`(예 `Bleed.png`). 비교판·임시는 밑줄로 시작(`_sheet.png`).
- 카드: `art/cards/<CardId>.png`(예 `Duelist_R_Bloodletting.png`). 견본은 `sample_` 접두사.
- 만든 스크립트: `tools/art/<이름>.py`, 공용 도구는 `tools/art/artlib.py`. 파일을 직접 고치지 말고 스크립트를 고쳐 다시 돌린다.

## 6. 로블록스 업로드·코드 연결 (총괄이 할 일)

1. **업로드 규격**: PNG, 정사각, 최대 1024×1024(우리는 256·512), 파일당 20MB 이하, sRGB, 알파 있음. 스튜디오 Asset Manager → Images → Bulk Import 로 `art/status/*.png`(37장) 올리면 한 번에 가능. 심사 통과 후 각 이미지의 asset id(숫자)를 얻는다. (UI 이미지는 `Image = "rbxassetid://<id>"`.)
2. **연결 위치(제안, 아직 안 만듦)**: 새 모듈 `src/shared/ArtAssets.luau` — `Status = { Bleed = "rbxassetid://…", … }`, `Cards = { [카드Id] = "rbxassetid://…" }`. 키는 `Keywords` Id / 카드 Id 와 같다.
3. **상태이상**: `src/client/BattleHud.luau`의 `statusChips`(글자 칩, 약 826~909행)에서 `ArtAssets.Status[id]`가 있으면 칩 왼쪽에 `ImageLabel`(표시 크기 24~32px, 실표시 48px)을 넣고 수치는 우하단에. 없으면 지금 글자 칩 그대로(안전한 폴백). 툴팁(`Keywords` 설명)은 그대로.
4. **카드 그림**: `src/client/CardView.luau`의 `PaintArt`(약 90행)에서 `ArtAssets.Cards[card.Id]`가 있으면 도형 대신 `ImageLabel`(`ScaleType = Crop`, 정사각 캔버스 자리)을 쓰고, 없으면 지금 도형 경로로 폴백. 등급색 원판·메달리온은 새 그림에선 그림 자체에 테두리가 있으므로 `CardArt.For`의 원판 도형은 건너뛴다.
5. 이미지 업로드는 심사를 거치므로 한 번에 몰아서 올린다. 그림을 고치면 asset id 가 바뀌므로 `ArtAssets.luau`만 갱신하면 되게 해 둔다.
6. 이번 1차에서 `src/**`는 건드리지 않았다.
