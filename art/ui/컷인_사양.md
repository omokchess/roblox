# FINISHER / PIN! 컷인 사양 (아트팀, 2026-11-06)

**결정: 이미지가 아니라 TextLabel 로 그린다.** 이유 — (1) 부제를 한 글자씩 내는 연출(`MaxVisibleGraphemes`)과 글자 색·언어 교체가 쉽다, (2) 업로드·심사 없이 코드만으로 끝, (3) 해상도 무관하게 선명. 시안 `finisher_cutin.png`·`pin_cutin.png`(1280×720)는 **배치·색·비율의 기준 그림**이며 시안 글꼴은 Times Bold/맑은 고딕이라 실제 글꼴과 글자 모양만 조금 다르다. 시안 재생성: `blender.exe -b -P tools/art/finisher_cutin.py`.

기준 화면 1280×720. 크기는 전부 Scale, 글자만 `TextSize` 100(로블록스 상한)에 `UIScale` 로 화면에 맞춘다(`UIScale.Scale = 화면높이/720`).

## 구성 (위에서 아래로 ZIndex)

1. **검은 띠** `Frame`
   - `AnchorPoint (0.5, 0)`, `Position {0.5,0, 0.14,0}`, `Size {1,0, 0.264,0}`(= 190px/720)
   - `BackgroundColor3 (0,0,0)`, `BackgroundTransparency 0.1`, `BorderSizePixel 0`
   - 연출: 처음 `Position.Y = -0.264`(화면 위 밖)에서 0.14 로 `Quint Out` 0.35초 내려옴. 끝날 때 반대로 0.3초.
   - 띠 위·아래 가장자리에 금빛 선 `Frame` 둘: 높이 3px, `BackgroundColor3 (201,162,74)`(`#c9a24a`)
2. **큰 글자** `TextLabel` (FINISHER 또는 PIN!)
   - `Font = Enum.Font.Bodoni`(굵기 대비 큰 세리프 — 로블록스에서 가장 가깝다. 마음에 안 들면 `Enum.Font.Garamond`), `TextSize 100`, `Text = "FINISHER"`, `BackgroundTransparency 1`
   - 자리: 띠 안 위쪽. `Position {0.5,0, 0.2,0}`(띠 기준) `AnchorPoint (0.5,0)`, `Size {1,0, 0.62,0}`
   - 자간이 넓어 보이게 글자 사이에 얇은 공백(`\u{200A}`)을 끼우거나, 글자마다 `TextLabel`을 만들어 **한 글자씩 등장** 시켜도 좋다.
3. **글자 채움**: `UIGradient`(큰 글자에) `Rotation 90`, `Color = ColorSequence( 0:(255,255,255), 1:(169,180,200) )`(은백 위→아래). `TextColor3`은 흰색 (255,255,255) 로 두어야 그라디언트가 제 색으로 나온다.
4. **테두리** `UIStroke`(큰 글자에): `ApplyStrokeMode = Contextual`, `LineJoinMode = Round`
   - FINISHER: `Color (224,184,76)`(`#e0b84c` 금), `Thickness 4`
   - 바깥 그림자는 같은 글자를 한 겹 더(검정, 투명도 0.4, 위치 +0,+4) 깔면 된다.
5. **부제** `TextLabel`
   - `Font = Enum.Font.GothamMedium`(한글은 로블록스 기본 대체 글꼴로 나온다. 라틴·한글이 섞이므로 세리프를 쓰지 않는다), `TextSize 34`, `TextColor3 (215,222,234)`(`#d7deea`)
   - 자리: 띠 아래쪽. `Position {0.5,0, 0.74,0}`(띠 기준) `AnchorPoint (0.5,1)`, `Size {1,0, 0.22,0}`
   - 글자 사이 벌림이 시안의 느낌: 각 글자 뒤에 `\u{200A}\u{200A}` 를 넣는다.
   - `UIStroke`: `Color (0,0,0)`, `Thickness 2`, Contextual
   - **한 글자씩 등장**: `MaxVisibleGraphemes` 를 0 → 글자 수까지 0.045초 간격으로 올린다(글자 수 `utf8.len(text)`). 큰 글자 등장이 끝난 0.3초 뒤에 시작.
   - FINISHER 부제 문구: `빈 별자리 · KENOS ASTERISMOS`

## PIN! 컷인 (같은 양식, 금색)

- 띠·금빛 선·부제 `Font`·구도는 FINISHER 와 **전부 같다**. 바뀌는 것만:
  - 큰 글자 `Text = "PIN!"`
  - `UIGradient` 색: 0:(255,243,176) → 1:(224,169,44)(밝은 금 → 진한 금)
  - `UIStroke` 색 (106,70,8)(`#6a4608`, 진한 갈색 금), `Thickness 4`
  - 부제 `핀 성공 · PIN FALL`, `TextColor3 (244,227,168)`(`#f4e3a8`)
  - 등장은 글자가 아래서 `Back Out`으로 튀어 오르는 0.25초(PIN! 은 짧으니까 한 글자씩 대신 통째로)

## 소리·타이밍 (모션 및 이펙트 부서 참고)
띠 0.35초 내려옴 → 큰 글자 등장 0.3초 → 부제 한 글자씩 → 유지 → 퇴장 0.3초, 합쳐 1.8초. 효과음은 낮은 종 4타를 글자 등장에 맞춘다.
